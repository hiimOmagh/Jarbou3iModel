# v1.0.21 — Node 24 CI Compatibility + Action Runtime Migration

## Observation

GitHub Actions reported that Node.js 20-based actions are deprecated and will be forced to run on Node 24 by default in 2026. The v1.0.20 browser pipeline was already functionally close to green after the hosted-demo evidence accordion hotfix, so this patch keeps scope limited to CI/runtime compatibility.

## Diagnosis

The workflow still used Node 20-era action majors:

- `actions/checkout@v4`
- `actions/setup-node@v4`
- `actions/upload-artifact@v4`
- `node-version: 20`

That creates future CI fragility even if the application code itself remains stable.

## Correction

v1.0.21 updates the CI workflow to:

- `actions/checkout@v6`
- `actions/setup-node@v6`
- `actions/upload-artifact@v6`
- `node-version: 24`

The install path remains locked and deterministic:

```bash
node tests/lockfile-public-registry-check.mjs
npm ci --no-audit --no-fund --ignore-scripts
```

Browser CI still installs Playwright once at workflow level and then runs:

```bash
PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser
```

## Boundaries

No runtime capability expansion was added.

- No live scraping.
- No real OAuth or PKCE.
- No provider behavior expansion.
- No backend endpoint expansion.
- Manual/private mode remains default.

## Validation

Required gates:

```bash
npm run test:ci:node24
npm run test:v121:no-browser
npm run test:ci:no-browser
npx playwright install --with-deps
PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser
```
