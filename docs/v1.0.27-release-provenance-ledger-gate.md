# v1.0.27 — Release Provenance Ledger Gate

## Purpose

v1.0.27 adds a release provenance ledger to the public-demo release chain. The patch records the intended base version, target version, artifact name, changed-files-only boundary, manifest/SHA handoff expectation, and required CI revalidation commands.

## What changed

- Added `release_provenance_ledger` metadata to research packets.
- Added `src/research/release-provenance-ledger.js`.
- Added `tests/release-provenance-ledger-check.mjs`.
- Added `tests/v127-no-browser-suite.mjs`.
- Updated schema, migrations, current fixtures, release docs, package scripts, and no-browser CI syntax coverage.

## Boundary

This is a release-trust patch only. It does not add live scraping, production OAuth, new provider behavior, backend endpoint expansion, source connector expansion, storage expansion, or public-demo capability expansion.

## Required validation

```bash
npm run test:release-provenance-ledger
npm run test:v127:no-browser
npm run test:ci:no-browser
PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser
```

## Release rule

A named artifact is not sufficient provenance by itself. The changed-files manifest, artifact SHA256, intended base version, and green no-browser/browser CI must all be reviewed before public release.
