# v1.0.20 — Source Packet Template Browser QA + Copy Safety

v1.0.20 consolidates the unresolved v1.0.19 CI fixes and hardens Source Packet Template Presets in browser QA.

## Scope

- Browser-test template selector visibility across desktop, tablet, and mobile.
- Browser-test all source packet template presets:
  - official report
  - Reddit thread
  - YouTube transcript
  - market signal
  - GitHub release
  - generic article
- Guard copy/export controls so generated source packet JSON remains visible, reachable, and safe.
- Prevent visual regression desktop captures from running under the mobile Playwright project.
- Prevent duplicate Playwright browser installation in CI when GitHub Actions already installed browsers.
- Keep repository hygiene gates defensive against stale `XX*` orphan files.

## Explicit non-scope

- No live scraping.
- No production OAuth.
- No BrainLink/OpenRouter PKCE implementation.
- No provider behavior expansion.
- No backend endpoint expansion.
- No claim that template packets verify source truth.

## Compatibility boundary

Manual/private mode remains the default. Template output is a local drafting scaffold and transport format. It performs no live fetching and makes no verification claim.

## Added gates

```bash
npm run test:browser:visual-scope
npm run test:source:packet-template-browser-qa
npm run test:v120:no-browser
```

## Browser gates

```bash
npm run test:browser:source-packet-template
PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser
```

## Release gate

Do not mark v1.0.20 complete until both no-browser CI and browser CI pass, and until any tracked stale orphan file such as `src/XXvKXvVS` is deleted by Git commit.

## Browser evidence hotfix note

The hosted-demo evidence capture now opens the advanced Provider Harness accordion before asserting `#providerName`. This matches the v1.0.4+ screen-discipline behavior where advanced panels are intentionally collapsed by default.

The quality/export evidence capture now asserts visible controls that belong to the Quality & Export tab: `#researchQualityOutput` and `#exportSourcePacketBuilderBtn`. It no longer checks `#exportWorkflowBtn` from the Evidence tab while the Quality & Export tab is active.
