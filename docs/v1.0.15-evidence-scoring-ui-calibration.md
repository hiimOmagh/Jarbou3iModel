# v1.0.15 — Evidence Scoring UI Explanation + Calibration Pass

v1.0.15 adds an interpretation layer around Evidence Scoring v1. The scoring algorithm remains `evidence_scoring.v1`; this patch adds `evidence_scoring_calibration.v1` to make score meaning explicit in the UI, schema, fixtures, and CI checks.

## Purpose

Prevent score theater. Evidence scores must support review and prioritization, not pretend to determine truth automatically.

## Added

- Interpretive bands for reliability, attention, traceability, and synthesis weight.
- Calibration warnings for attention-dominant evidence and weak traceability.
- Score-theater guard: `scores_explain_prioritization_not_truth`.
- UI copy explaining that attention is public visibility only.
- Versioned calibration tests and fixtures.

## Preserved boundary

- No live scraping.
- No production OAuth.
- No BrainLink/OpenRouter PKCE integration.
- No provider behavior change.
- No backend endpoint behavior change.
- No source connector behavior change.
- No storage behavior change.
- Manual/private mode remains default.
- Imported evidence remains review-gated.
