# v1.0.12 — Research Source Strategy Blueprint

## Purpose

v1.0.12 converts the recent source/auth inspiration review into a conservative strategy layer. It adds a source capability registry that classifies each source or external workflow by availability, auth mode, freshness, evidence type, privacy risk, and public-demo visibility.

## What changed

- Added `src/research/source-capability-registry.js`.
- Added `source_capability_registry` metadata to exported research packets.
- Added schema and fixture coverage for the registry.
- Added `tests/source-capability-registry-check.mjs`.
- Added `tests/v112-no-browser-suite.mjs`.
- Extended no-browser CI syntax and stable/patch gates.

## Compatibility boundary

- No live Reddit, X, YouTube, TikTok, HN, Polymarket, or NotebookLM collection was added.
- No production OAuth or portable-account provider was enabled.
- No provider behavior changed.
- No backend endpoint behavior changed.
- No storage behavior changed.
- Manual/private mode remains the default.

## Strategic rule

Engagement is not truth. Public signal strength must stay separate from evidence reliability.
