# v1.0.24 — Repo Hygiene Execution + Stale Documentation Correction

## Observation

v1.0.23 closed the CI/browser evidence loop: both no-browser and browser jobs are now green, including RTL/mobile and runtime accessibility fixes. The remaining release risk is repository drift: stale documentation can describe older capabilities, versioned fixtures can miss the current patch, and generated artifacts can leak into the committed tree or release archive.

## Diagnosis

The release process had correct guardrails, but several documentation surfaces still described an older `v0.20.0-beta` state. That creates a false capability map for operators and reviewers. The project must also preserve a hard distinction between committed source files and generated artifacts such as ZIPs, Playwright reports, `test-results`, `node_modules`, and local secret files.

## Correction

v1.0.24 executes the hygiene layer instead of adding product capability:

- promotes the current release metadata to `v1.0.24`;
- adds v1.0.24 migration and privacy export fixtures;
- corrects stale current-state documentation in `docs/ai-integration.md`, `docs/architecture.md`, and `docs/privacy-audit.md`;
- fixes the historical heading mismatch in `docs/v0.19.0-beta-privacy-audit-hardening.md`;
- adds a dedicated repo-hygiene/stale-docs guard;
- keeps generated artifacts outside the committed repository and release archive boundary;
- preserves Node 24, deterministic `npm ci`, and Playwright install discipline;
- preserves the public-demo/manual/private runtime boundary.

## Required hygiene checks

| Check | Expected result |
|---|---|
| Version metadata | package, lockfile, schema, current fixtures, migration target identify v1.0.24 |
| Historical continuity | v1.0.23 release doc and fixtures remain present |
| Stale docs | current-state docs no longer claim v0.20.0-beta as current |
| Artifact boundary | no ZIPs, logs, temp files, `node_modules`, `test-results`, or Playwright reports in source tree |
| Release archive boundary | `.releaseignore` excludes generated outputs, secrets, ZIPs, and reports |
| CI wiring | no-browser CI runs the hygiene guard and syntax-checks the v1.0.24 wrapper |
| Runtime boundary | no live scraping, production OAuth, provider behavior, backend endpoint, source connector, or storage behavior expansion |

## Validation

Required gates:

```bash
npm run test:repo:hygiene-execution
npm run test:v124:no-browser
npm run test:ci:no-browser
npx playwright install --with-deps
PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser
```

## Release decision rule

Approve v1.0.24 only if the repository tree is clean, the stale current-state documentation is corrected, both CI gates are green, and the browser evidence artifact remains evidence-only rather than release approval.

## Compatibility boundary

This patch is release-hygiene only. It must not alter provider behavior, OAuth behavior, backend endpoint behavior, source connector behavior, storage behavior, source verification behavior, or public-demo capability surface.
