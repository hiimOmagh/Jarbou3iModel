# v1.0.13 — Manual Source Packet Import

## Scope

v1.0.13 adds a local/manual structured source packet import path. It converts user-collected JSON source packets into evidence candidates and routes them through the existing Evidence Review Queue before they can enter the Evidence Matrix.

## What changed

- Added `src/research/source-packet-importer.js`.
- Extended `src/research/source-import-adapter.js` with `source_packet` detection and parsing.
- Added `fixtures/research/source-packet-sample.json`.
- Added `tests/source-packet-import-check.mjs`.
- Added v1.0.13 migration/privacy fixtures and schema coverage.
- Updated source capability metadata so `manual_source_packet` is available as a manual, non-live import path.

## Runtime boundary

No live source connector was enabled.

No scraping was enabled.

No OAuth or portable-auth production path was enabled.

No provider behavior, backend endpoint behavior, or storage behavior changed.

Imported packets are explicitly marked as unverified manual imports and remain review-gated.

## Acceptance criteria

- Source packet JSON imports produce reviewable evidence candidates.
- Imported candidates carry source metadata, engagement metadata, and review warnings.
- `live_fetching_performed` remains `false`.
- `verification_claimed` remains `false`.
- Schema, fixtures, migration, privacy, source import, and source capability checks pass.
