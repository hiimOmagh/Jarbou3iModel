# v1.0.18 — Source Packet Builder Export Roundtrip QA

## Purpose

v1.0.18 proves the local/manual Source Packet Builder can export a manual source packet and re-import it without changing trust boundaries.

## Scope

- Add source packet export/import roundtrip QA.
- Preserve builder scoring review metadata during import.
- Confirm re-imported evidence remains queue-only and unverified.
- Confirm re-imported evidence receives evidence scoring.
- Confirm no live fetching, no production OAuth, and no provider behavior change.

## Non-goals

- No live Reddit/X/YouTube/TikTok/Hacker News/Polymarket connector.
- No BrainLink/OpenRouter PKCE production integration.
- No source verification claim.
- No backend endpoint change.

## Acceptance criteria

- Generated source packet has `manual_source_packet.v1` shape.
- Re-import uses the source-packet importer.
- Re-import report keeps `live_fetching_performed: false` and `verification_claimed: false`.
- Scoring review metadata is preserved as import metadata.
- Re-imported evidence has `evidence_scoring.v1` metadata.
- Exported and re-imported evidence counts match.

npm run test:source:packet-roundtrip
