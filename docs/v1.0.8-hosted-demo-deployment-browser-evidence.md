# v1.0.8 — Hosted Demo Deployment Verification + Browser Evidence Capture

v1.0.8 adds hosted-demo deployment verification and browser evidence capture to make the public demo publishable with proof rather than assumption.

## Added

- Hosted-demo verification module and packet metadata.
- Browser evidence capture metadata for desktop, mobile, provider-mode, and quality/export states.
- Hosted-demo verification panel in the first screen.
- Playwright browser-evidence spec for publish-time screenshots.
- No-browser hosted-demo deployment gate.
- Stronger repo hygiene detection for stray `XX*` temp artifacts.

## Unchanged

- No provider behavior change.
- No OAuth behavior change.
- No backend endpoint behavior change.
- No source connector behavior change.
- No storage behavior change.
- Manual/private mode remains the default.

## Required publishing gate

Run no-browser CI first, then browser CI with evidence capture. A hosted deployment should not be treated as publish-ready until the evidence artifacts are attached or reviewed.
