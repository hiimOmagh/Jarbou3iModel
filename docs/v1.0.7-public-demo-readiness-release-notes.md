# v1.0.7 — Public Demo Readiness + Release Notes Polish

## Purpose

v1.0.7 prepares the stable research engine for a public demo and handoff. It focuses on presentation readiness, release-note clarity, and metadata gates that make the public-facing state explicit.

## What changed

- Added public-demo readiness metadata to exported research packets.
- Added release-note metadata to exported research packets.
- Added a public demo readiness panel to the first screen.
- Added a public demo operator checklist and demo script.
- Added schema and fixture coverage for public-demo and release-note metadata.
- Added a dedicated no-browser public-demo readiness test.

## What did not change

- No provider behavior changed.
- No OAuth behavior changed.
- No backend endpoint behavior changed.
- No source connector behavior changed.
- No production OAuth path was enabled.
- No live source fetching was enabled.
- Manual/private mode remains the default.

## Acceptance criteria

- A visitor can understand the intended first-run path without opening advanced internals.
- Release notes clearly separate visible polish from unchanged runtime boundaries.
- Exported packets include demo readiness and release-note metadata.
- Privacy/export guardrails remain unchanged.
- CI has a public-demo readiness gate.

## Required validation

```bash
npm run test:public-demo
npm run test:ci:no-browser
npm run test:ci:browser
```

Browser tests remain required before publishing a hosted public demo.
