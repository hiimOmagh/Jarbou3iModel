# v1.0.9 — Hosted Demo Smoke Fixes + Evidence Review

v1.0.9 converts hosted-demo proof from loose Playwright attachments into a stable evidence bundle that can be reviewed before publishing.

## Scope

- Support `HOSTED_DEMO_URL` in Playwright config so the evidence spec can run against the real deployed URL.
- Keep local static-server browser QA available when `HOSTED_DEMO_URL` is not set.
- Capture desktop, mobile, provider-mode, and quality/export screenshots.
- Write `test-results/hosted-demo-evidence/hosted-demo-metadata.json` for version and panel verification.
- Add export-safe `hosted_demo_smoke_fixes` and `hosted_demo_evidence_review` packet sections.
- Add no-browser gates for smoke-fix and evidence-review completeness.

## Compatibility boundary

No provider, OAuth, backend, source, or storage behavior changed. The patch is QA/release-proof only.

## Hosted URL command

```bash
HOSTED_DEMO_URL="https://example.github.io/jarbou3i-research-engine" npm run test:browser:evidence
```

## Browser Evidence artifacts

Expected artifact root:

```text
test-results/hosted-demo-evidence
```

Expected files:

```text
desktop-first-screen.png
mobile-first-screen.png
provider-mode.png
quality-export.png
hosted-demo-metadata.json
```

## Review requirement

Before publishing the hosted demo, review:

- desktop screenshot
- mobile screenshot
- provider-mode screenshot
- quality/export screenshot
- metadata snapshot
- version consistency
- privacy/export boundary indicators

The evidence review release gate is `evidence_review_complete` only when all required review items are present.
