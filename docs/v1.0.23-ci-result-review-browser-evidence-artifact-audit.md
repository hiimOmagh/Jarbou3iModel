# v1.0.23 — CI Result Review + Browser Evidence Artifact Audit

## Observation

v1.0.22 verifies the local release evidence boundary and repository hygiene controls. The remaining release risk is external: a local archive can pass while the public GitHub Actions workflow, uploaded browser evidence, or deployed artifact still reflects an older commit or older CI shape.

## Diagnosis

Evidence upload is not release approval. The exact audit phrase is: evidence upload is not release approval. A browser evidence artifact can exist even when a job fails, is stale, or was generated by a workflow that does not match the current source archive. GitHub Actions status must therefore be reviewed against the exact commit SHA that will be released.

The public repository audit performed during this patch found a release-alignment risk: the visible public GitHub Actions run for `hiimOmagh/Jarbou3i_Model` still showed an older workflow shape using `actions/checkout@v4`, `actions/setup-node@v4`, `node-version: 22`, and `npm install`. That public state does not match the uploaded v1.0.22 source archive, which already contains Node 24, deterministic `npm ci`, split no-browser/browser jobs, and evidence artifact upload discipline.

## Correction

v1.0.23 adds a dedicated CI result and browser evidence audit contract. It requires reviewers to verify:

- exact GitHub Actions run URL and commit SHA;
- no-browser job status;
- browser job status;
- Node 24 workflow shape;
- deterministic `npm ci --no-audit --no-fund --ignore-scripts` install path;
- Playwright installed once before `PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser`;
- browser evidence artifact exists and is inspectable;
- artifact upload is treated as inspection data, not release approval;
- external deployed/public repository state matches the release archive before public release.

## Required audit fields

| Field | Required value |
| --- | --- |
| Release commit SHA | exact SHA from GitHub Actions run |
| CI run URL | exact run URL |
| no-browser job | success |
| browser job | success |
| hosted demo evidence artifact | present and inspectable |
| artifact verdict | evidence only, not approval |
| workflow action majors | Node 24-compatible action versions |
| install path | `npm ci --no-audit --no-fund --ignore-scripts` |
| browser install path | `npx playwright install --with-deps` before skip-flag browser CI |
| public repository alignment | package, workflow, and docs match uploaded release archive |

## Validation

Required gates:

```bash
npm run test:ci:result-review
npm run test:v123:no-browser
npm run test:ci:no-browser
npx playwright install --with-deps
PLAYWRIGHT_SKIP_INSTALL=1 npm run test:ci:browser
```

## Release decision rule

Do not approve v1.0.23 from a local ZIP alone. Approve only when the GitHub Actions run for the intended release commit shows both no-browser and browser jobs passing, the uploaded browser evidence artifact is reviewed, and the public repository state matches the release archive.

## Compatibility boundary

This patch is audit-only. It must not alter provider behavior, OAuth behavior, backend endpoint behavior, source connector behavior, storage behavior, or user-visible product capability.
