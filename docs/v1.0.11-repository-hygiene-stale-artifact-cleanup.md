# v1.0.11 — Repository Hygiene + Stale Artifact Cleanup

v1.0.11 is a patch-only cleanup release. It tightens repository hygiene, repairs migration fixture coverage, and adds release-drift checks without changing browser runtime behavior, provider behavior, OAuth behavior, backend endpoint behavior, source connector behavior, or storage behavior.

## Scope

- Add a dedicated repository hygiene cleanup gate for v1.0.11.
- Add a v1.0.11 no-browser suite wrapper.
- Add v1.0.11 migration and privacy snapshots.
- Add a missing v1.0.4 migration fixture so every supported stable source version has fixture coverage.
- Keep stale temporary artifacts, generated outputs, local secrets, root ZIP archives, duplicate release docs, and unexpected versioned docs blocked by CI.
- Keep v1.0.10 module-type warning validation active.

## Compatibility boundary

This patch must not change:

- provider behavior
- OAuth behavior
- backend endpoint behavior
- source connector behavior
- browser runtime feature surface
- local storage model
- public-demo truthfulness boundary
- privacy export safety rules
