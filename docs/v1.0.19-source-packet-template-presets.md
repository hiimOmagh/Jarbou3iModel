v1.0.19 adds local/manual Source Packet Template Presets for common source types without enabling live fetching, scraping, OAuth, provider changes, backend endpoint changes, or storage behavior changes.

## Template presets

- Official report / institutional document
- Reddit thread / public discussion
- YouTube video / transcript
- Prediction market / market signal
- GitHub release / repository signal
- Generic article / web source

## Guardrails

- Template output is a drafting scaffold, not source verification.
- `live_fetching_performed` remains `false`.
- `verification_claimed` remains `false`.
- Source packets still route through manual import and review discipline.
- Attention signals remain separate from reliability.

## Boundary

No provider, OAuth, backend, source connector, or storage behavior changed.
