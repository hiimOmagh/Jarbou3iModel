# v1.0.16 — Source Packet Builder UI + Scoring Review Controls

Patch scope: local/manual source packet builder UI and scoring review controls.

## What changed

- Added `src/research/source-packet-builder.js`.
- Added a Source Packet Builder UI card.
- Added build-from-evidence and build-from-review-queue actions.
- Added copy/export actions for manual source packet JSON.
- Added scoring review controls for review-queue candidates.
- Added `source_packet_builder_report` and `last_built_source_packet` to exported research packets.
- Added `tests/source-packet-builder-check.mjs` and `tests/v116-no-browser-suite.mjs`.

## Preserved boundaries

- No live scraping.
- No production OAuth.
- No BrainLink/OpenRouter PKCE production integration.
- No provider behavior change.
- No backend endpoint behavior change.
- No source connector behavior change.
- Manual/private mode remains default.
- Builder output is transport metadata, not source verification.
