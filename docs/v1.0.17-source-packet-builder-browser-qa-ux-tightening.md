# v1.0.17 — Source Packet Builder Browser QA + UX Tightening

## Purpose

This patch verifies and tightens the browser-facing Source Packet Builder introduced in v1.0.16.

The patch does not add live scraping, production OAuth, provider behavior changes, backend endpoint changes, source connector behavior changes, storage behavior changes, or schema-breaking workflow changes.

## Changes

- Added browser-QA hooks for the Source Packet Builder card.
- Added explicit local/manual guardrail copy in the builder UI.
- Added responsive action layout for build, copy, and export controls.
- Added bounded metadata preview for generated source packets.
- Added output `aria-live="polite"` for builder status updates.
- Added overflow-safe CSS for builder chips, warning blocks, and preview content.
- Ensured the Source Packet Builder appears under the Sources and Quality tabs rather than being hidden under Advanced only.
- Added static browser-QA guard checks.
- Added a dedicated Playwright spec for builder visibility, overflow, and no-live/no-verification semantics.

## Boundary preserved

- Manual/private mode remains default.
- Builder output remains a local/manual transport format.
- No live fetching is performed.
- No source verification is claimed.
- Imported or built evidence remains review-gated.
- Provider, OAuth, backend, and storage behavior are unchanged.

## Validation

Required no-browser checks:

```bash
npm run test:source:packet-builder:browser-qa
npm run test:source:packet-builder
npm run test:v117:no-browser
npm run test:ci:no-browser
```

Required browser check before publishing:

```bash
npm run test:browser:source-packet-builder
npm run test:ci:browser
```
